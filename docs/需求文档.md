# 番茄病虫害识别系统 - 需求文档

## 1. 项目概述

### 1.1 项目名称
番茄病虫害识别与防治建议系统

### 1.2 项目目标
构建一个多 Agent 协作的农业智能咨询系统，专注于番茄病虫害识别，为农户提供专业的防治建议。

### 1.3 目标用户
- 番茄种植农户
- 农业技术人员
- 农业研究机构

## 2. 功能需求

### 2.1 用户交互层

#### 2.1.1 图片上传
- 支持上传 JPG、PNG、BMP、WebP 格式的图片
- 图片大小限制：10MB
- 支持拖拽上传
- 图片预览功能

#### 2.1.2 文字输入
- 支持用户输入文字描述症状
- 文本长度限制：1000 字符
- 智能提示功能

#### 2.1.3 位置信息
- 浏览器自动定位
- IP 地址定位
- 用户手动输入位置
- 三种方式可选，优先级：浏览器 > 手动 > IP

### 2.2 输入理解层

#### 2.2.1 图像处理
- 图像预处理（缩放、格式转换）
- 特征提取（颜色、纹理）
- 图像描述生成

#### 2.2.2 文本处理
- 关键词提取
- 症状识别
- 严重程度判断
- 位置信息提取

### 2.3 病虫害识别模型层

#### 2.3.1 模型接口
- 预留 EfficientNet/ResNet/CLIP 模型接口
- 支持模型热加载
- 识别结果置信度

#### 2.3.2 识别结果
- 病害名称
- 置信度
- 症状列表
- 是否健康判断

### 2.4 智能体层

#### 2.4.1 Supervisor Agent
- 任务拆解与调度
- Agent 协调管理
- 结果汇总

#### 2.4.2 病害知识 Agent
- 病害知识分析（预留 RAG 接口）
- 病害成因分析
- 传播途径分析
- 防治建议生成

#### 2.4.3 天气 Agent
- 天气数据查询（彩云 API）
- 天气对病害影响分析
- 施药天气建议

#### 2.4.4 土壤分析 Agent
- 土壤状况分析（基于位置）
- 土壤与病害关系分析
- 土壤改良建议

#### 2.4.5 灌溉 Agent
- 灌溉需求分析
- 灌溉方式建议
- 灌溉计划生成

#### 2.4.6 安全用药 Agent
- 农药推荐（预留数据库接口）
- 用药安全性分析
- 安全提醒生成

#### 2.4.7 种植日历 Agent
- 农事日历生成
- 农事提醒
- 阶段性管理计划

#### 2.4.8 记忆 Agent
- 用户历史记录管理
- 诊断模式分析
- 个性化建议生成

### 2.5 综合决策层

#### 2.5.1 LLM 汇总
- 综合所有 Agent 分析结果
- 生成最终防治建议
- 建议内容结构化

### 2.6 数据存储

#### 2.6.1 用户档案
- 用户基本信息
- 位置信息
- 注册时间

#### 2.6.2 诊断记录
- 图片路径
- 文字输入
- 各 Agent 分析结果
- 最终建议
- 诊断时间

#### 2.6.3 用户记忆
- 记忆类型（偏好/历史/知识）
- 记忆内容
- 元数据

## 3. 非功能需求

### 3.1 性能需求
- 图片上传响应时间 < 5 秒
- 诊断结果生成时间 < 30 秒
- 支持并发用户数 > 10

### 3.2 可用性需求
- 界面简洁易用
- 支持移动端访问
- 中文界面

### 3.3 可扩展性需求
- 模型接口可扩展
- Agent 可扩展
- 知识库可扩展

### 3.4 安全需求
- 用户数据本地存储
- API 访问控制
- 文件上传安全检查

## 4. 技术架构

### 4.1 后端架构
- Web 框架：FastAPI
- 数据库：SQLite + SQLAlchemy
- LLM：智谱 AI GLM-4
- 图像处理：Pillow

### 4.2 前端架构
- 框架：Vue.js 3
- 构建工具：Vite
- UI 框架：Bootstrap 5
- HTTP 客户端：Axios

### 4.3 Agent 架构
- 基类：BaseAgent
- 调度：SupervisorAgent
- 专业 Agent：7 个并行执行

## 5. 接口设计

### 5.1 API 接口

#### 诊断接口
```
POST /api/diagnosis
Content-Type: multipart/form-data

参数：
- file: 图片文件（可选）
- request: JSON 字符串
  - text_input: 文字描述（可选）
  - latitude: 纬度（可选）
  - longitude: 经度（可选）
  - location: 位置描述（可选）
  - browser_location: 浏览器定位结果（可选）

返回：
{
  "success": true,
  "diagnosis_id": 1,
  "disease_result": {...},
  "weather_analysis": {...},
  "soil_analysis": {...},
  "irrigation_advice": {...},
  "safety_advice": {...},
  "calendar_advice": {...},
  "memory_analysis": {...},
  "final_advice": "..."
}
```

#### 历史记录接口
```
GET /api/history?limit=10

返回：
{
  "success": true,
  "records": [...],
  "total": 10
}
```

#### 用户档案接口
```
GET /api/user/profile

返回：
{
  "success": true,
  "user_info": {...},
  "statistics": {...},
  "recent_diagnoses": [...]
}
```

## 7. 部署说明

### 7.1 开发环境
1. 安装 Python 3.12+
2. 安装 Node.js 16+
3. 安装依赖：`pip install -r requirements.txt`
4. 启动后端：`python main.py`
5. 启动前端：`cd frontend && npm install && npm run dev`

### 7.2 生产环境
1. 构建前端：`cd frontend && npm run build`
2. 配置 Nginx 反向代理
3. 使用 Gunicorn 启动后端
4. 配置 SSL 证书（可选）
